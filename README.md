# Cabaña Sol del Llao — sitio web

Esta carpeta contiene la versión completa y editable del sitio web de Cabaña Sol del Llao. Puede guardarse como respaldo, abrirse en una computadora o entregarse a otra persona/IA para continuar el trabajo.

## Cómo verlo en una computadora

Abrir `index.html` con doble clic. Para que se comporte igual que la vista previa, se recomienda abrir la carpeta con Visual Studio Code y usar una extensión de servidor local, como **Live Server**.

La portada es `index.html`. Las demás secciones son archivos independientes: `cabana.html`, `galeria.html`, `experiencias.html`, `ubicacion.html`, `preguntas.html`, `resenas.html`, `reservas.html` y `disponibilidad.html`.

## Administración local

Abrir `admin.html` para cambiar el título, texto e imágenes de la portada. Los cambios se guardan solamente en el navegador y computadora donde se realizan; no reemplazan los archivos originales ni se publican todavía.

## Archivos principales

- `index.html`: portada.
- `styles.css` y los demás `.css`: apariencia y diseño.
- `assets/`: todas las fotografías y el logo.
- `reservas.html` y `disponibilidad.html`: opciones de reserva y calendario.
- `availability-booking.js`: calendario de ocupación de Booking, sin enlaces privados ni credenciales.
- `admin.html`, `admin.js`, `admin.css`, `site-settings.js`: administración local de la portada.

## Al continuar con otra IA

Subí este archivo ZIP completo o, si la plataforma no acepta ZIP, subí la carpeta descomprimida junto con este README. Podés indicarle:

> Este es el sitio estático de Cabaña Sol del Llao. Conservá el diseño, el español de Argentina y las fotos de `assets`. Trabajá sobre los archivos existentes. No elimines funciones ya creadas. El panel `admin.html` es local y todavía no es una administración online segura. Necesito que me expliques cada cambio de forma sencilla y me entregues siempre los archivos completos o un ZIP actualizado.

## Importante antes de publicar

Para editar el sitio desde cualquier lugar y que los cambios se vean en internet, hará falta publicarlo en un hosting y agregar un sistema de administración real con inicio de sesión y almacenamiento seguro de fotos. No subir contraseñas, enlaces privados de calendario ni claves de cuentas dentro de estos archivos.
